# Kmong Beauty Reference Images

Put 5 to 10 reference images in each category folder:

- `skincare/`
- `makeup/`
- `cleansing/`
- `hair_body/`
- `beauty_tool/`

These images will be analyzed to create real category design system JSON for
Kmong beauty detail pages.

The generated JSON will replace the MVP seed files in
`src/data/beauty-design-systems/` after review.
